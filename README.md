# 3D Periodic Table Personnel Visualizer

A senior-level 3D interactive web application built with Three.js (CSS3D) and Google Identity Services OAuth 2.0, rendering personnel data dynamically from Google Sheets across four distinct spatial formations.

## Features
- Secure Google OAuth login integration.
- Live data fetching from Google Sheets with built-in loading and error handling.
- Four 3D Layouts: Table (20x10), Sphere (1400 radius), Double Helix (intertwined strands), and Grid (5x4x10).
- Interactive legend filter and click-to-zoom card focus.
